# Инженерная школа — CRM (демо)

Веб-приложение (SPA) для учёта платных доп. занятий «Инженерной школы» МГТ.
Фронт работает на мок-данных в localStorage; backend-каркас — в `backend/`
(Django+DRF, см. `backend/README.md`), фронт на API пока не переключён.

## Демо

Деплой — GitHub Pages (ветка `gh-pages`, single-file бандл).

## Стек

React 19 · TypeScript · Vite (single-file build) · Tailwind 4 · Radix UI ·
zustand · react-hook-form + zod · tanstack-table · recharts · fuse.js

## Запуск локально

```bash
npm install
npm run dev     # http://localhost:5173
npm run build   # dist/index.html — один самодостаточный файл
```

## Режимы данных: демо и API

По умолчанию фронт работает на локальном сиде (localStorage). Для работы с backend'ом:

```bash
# 1) поднять API (см. backend/README.md)
cd backend && .venv\Scripts\python.exe manage.py migrate && .venv\Scripts\python.exe manage.py seed_demo && .venv\Scripts\python.exe manage.py runserver 8000

# 2) открыть фронт в api-режиме
#    dev: http://localhost:5173/?api   (или VITE_API_MODE=1 в .env)
```

Экран логина → `admin/admin123`, `teacher/teacher123`, `accountant/account123`. В api-режиме все чтения/мутации идут в `/api/v1` (session-cookie + CSRF), действия стора делегируются в backend и делают refresh состояния. Ведомости и дашборд считаются на сервере (`/statements`, `/dashboard`), доступны XLSX-выгрузки ведомости и реестра. Вернуться в демо: меню пользователя → «Подключить к серверу…» ↔ ссылка «Открыть демо-режим» на экране логина.

## Возможности

- **Обзор** — KPI, посещаемость, финансы, ближайшие занятия
- **Ученики** — реестр, договоры по учебным годам (уникальность № в году),
  карточка с проводками и историей зачислений
- **Журналы** — сетка ученики×даты, цикл отметок П/Н/Б/У, замены преподавателя,
  телефон родителя, мобильный режим «по занятию»
- **Платежи** — импорт выписки BePaid (CSV), авто-сопоставление по ФИО
  с учётом опечаток, очередь ручного сопоставления, разделение платежа
  между детьми, защита от дублей
- **Ведомости оплат** — остаток/сдано/израсходовано/остаток по проводкам,
  закрытие месяца
- **Акты** — генерация из журнала, ставка с датой действия, −13% / −1%,
  сумма прописью, выбор подписанта
- **Документы** — печатные формы: реестр, журнал, ведомость, акт,
  доп. соглашение из шаблонов
- **Роли** — администратор / преподаватель / бухгалтер (демо-переключатель)
- Цены и ставки с датой действия, деньги через проводки (ledger),
  аудит-лог всех изменений, встроенные самопроверки
  (Настройки → «Запустить проверки»)
